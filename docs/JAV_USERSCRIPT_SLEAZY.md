# JAV Userscript Release

For public installation and usage instructions, see [Sleazy: Peach userscript](https://sleazyfork.org/zh-CN/scripts/600821).

The script source, site list, and release copy are maintained by [peach-mitao/peach-userscript](https://github.com/peach-mitao/peach-userscript). User-facing installation, pairing, download channel, and permission notes are in that repository's [Sleazy release notes](https://github.com/peach-mitao/peach-userscript/blob/main/docs/SLEAZY.md).

Releases use the verified full artifact `dist/peach-jav.user.js`, keeping readable code and the AGPL-3.0-or-later license. The install match rules and the script's inline rules are built from the same site manifest. Sleazy syncs the script automatically from the latest GitHub Release, and syncs the English and Simplified Chinese descriptions from that repository's `docs/SLEAZY.md` and `docs/SLEAZY.zh-CN.md`; the script's default language must stay English, otherwise localized names identical to the default language are ignored by Sleazy. Peach updates the installed script and the backend site snapshot following the [artifact sync procedure](JAV_BROWSER.md#artifact-sync).

Sleazy's release rules and account security requirements are enforced by that site; the actual public address is whatever the successfully published script page shows.
